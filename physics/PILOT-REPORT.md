## Автоматическая подготовка

Ручных масок и креплений нет. Движение не содержит условий по имени/ID Уны;
ID ограничивает только доступ к платной подготовке пилота.

Пакет содержит четыре слоя: корпус (369 вершин), два шнура шлема (18 и 17)
и пояс со шнурами (42). Все три подвижных слоя получили материал `cord`;
отдельный свободный слой ткани этим прогоном не выделен. Крепления вычислены
из выбранных VLM масок SAM 3. Глубина — числовой `grey_depth` модели Small.
Размер и положение взяты из сохранённого нейтрального кадра видео.

Первый вариант с остаточными контурами шнуров отклонён после просмотра,
сохранён для аудита и заменён. Восстановление расширено на узкую полосу по
границе удалённой детали. QA дополнительно видит очищенный корпус отдельно.
Текущий пакет: средняя ошибка нейтрали `0.0019755` при лимите `0.025`,
все шесть VLM-критериев одобрены. В рендерах ±12° нет вывернутых треугольников.
Это проверка пакета и контрольных поз; она не подтверждает качество живого движения.

## Расходы

Подтверждено OpenRouter: **$0.1485981**, 11 вызовов, включая промежуточные
анализы и повторные проверки исправленных ассетов. Replicate: 15 уникальных
prediction ID, суммарное время вычисления из API `2.86460884` с.
Точная сумма Replicate пока не сверена с биллингом; `cost.complete=false`.
Пополнение $10 не считается фактическим расходом. Этапы, ID и известные суммы
сохранены в `costs.json` и журналах задания.

Один запрос с потерянным ответом был остановлен и сверён со списком predictions
до разрешённой повторной отправки; аудит сохранён рядом с заданием.
Для 429 сохраняется задержка перед повтором. Неопределённый POST без ID
автоматически не повторяется, в том числе под другим именем этапа.

## Исправление калибровки

Нейтраль больше не фиксируется по первому событию rotation vector. Добавлены
прогрев, окно стабильности, нормализация кватерниона и повторное выравнивание
кнопкой. Поворот экрана и возобновление запускают калибровку заново.
До готовности показывается подсказка держать телефон неподвижно.
Регрессии проверяют стартовую identity-ориентацию перед реальной позой,
наклоны в обе стороны, q/-q, некорректные значения и повторную калибровку.
Сборка APK, lint, 199 Android unit-тестов и 47 backend-тестов проходят.
Общий Android-прогон сначала прервался из-за нехватки места на Mac;
после очистки только промежуточных файлов и освобождения Robolectric sandbox
между классами полный повтор завершился без ошибок.
Пользователь после установки калибровки подтвердил сдвиг, но счёл его слишком слабым.
Регрессия на реальном пакете выявила смещение кончика шнура всего на 0.0237 px:
точные ограничения всех рёбер делали плоскую триангулированную сетку почти
жёсткой. Ограничения теперь допускают ограниченную деформацию материала,
а силы учитывают допустимое смещение конкретной детали. При умеренном наклоне
шнуры перемещаются на 5.6–10.9 px; при сильных воздействиях крепления сохраняются
и треугольники не выворачиваются. Корпус получил общий наклон до 8° вокруг
нижней опоры, найденной по геометрии, без индивидуальных настроек Уны.
Новые крайние рендеры повторно прошли VLM QA. Проверка этой версии на телефоне
и окончательное визуальное принятие ещё нужны.
