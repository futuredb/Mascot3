## Автоматическая подготовка

Ручных масок и креплений нет. Движение не содержит условий по имени/ID Уны;
ID ограничивает только доступ к платной подготовке пилота.

Пакет содержит четыре слоя: корпус (369 вершин), два шнура шлема (18 и 17)
и пояс со шнурами (42). Все три подвижных слоя получили материал `cord`;
отдельный свободный слой ткани этим прогоном не выделен. Крепления вычислены
из выбранных VLM масок SAM 3. Глубина — числовой `grey_depth` модели Small.
Размер и положение взяты из сохранённого нейтрального кадра видео.

Первый вариант с остаточными контурами шнуров отклонён после просмотра,
сохранён для аудита и заменён. Восстановление расширено на узкую полосу по
границе удалённой детали. QA дополнительно видит очищенный корпус отдельно.
Текущий пакет: средняя ошибка нейтрали `0.0019755` при лимите `0.025`,
все шесть VLM-критериев одобрены. В рендерах ±12° нет вывернутых треугольников.
Это проверка пакета и контрольных поз; она не подтверждает качество живого движения.

## Расходы

Подтверждено OpenRouter: **$0.1485981**, 11 вызовов, включая промежуточные
анализы и повторные проверки исправленных ассетов. Replicate: 15 уникальных
prediction ID, суммарное время вычисления из API `2.86460884` с.
Точная сумма Replicate пока не сверена с биллингом; `cost.complete=false`.
Пополнение $10 не считается фактическим расходом. Этапы, ID и известные суммы
сохранены в `costs.json` и журналах задания.

Один запрос с потерянным ответом был остановлен и сверён со списком predictions
до разрешённой повторной отправки; аудит сохранён рядом с заданием.
Для 429 сохраняется задержка перед повтором. Неопределённый POST без ID
автоматически не повторяется, в том числе под другим именем этапа.

прошли за 34.494 с. Проверены решатель на одинаковых входах при 30/60/120 FPS,

пересоздание TextureView. Это не равно испытанию принудительного EGL_CONTEXT_LOST

## Исправление калибровки

Нейтраль больше не фиксируется по первому событию rotation vector. Добавлены
прогрев, окно стабильности, нормализация кватерниона и повторное выравнивание
кнопкой. Поворот экрана и возобновление запускают калибровку заново.
До готовности показывается подсказка держать телефон неподвижно.
Регрессии проверяют стартовую identity-ориентацию перед реальной позой,
наклоны в обе стороны, q/-q, некорректные значения и повторную калибровку.
Сборка APK, lint, 204 Android unit-тестов и 47 backend-тестов проходят.
Общий Android-прогон сначала прервался из-за нехватки места на Mac;
после очистки только промежуточных файлов и освобождения Robolectric sandbox
между классами полный повтор завершился без ошибок.
Пользователь после установки калибровки подтвердил сдвиг, но счёл его слишком слабым.
Регрессия на реальном пакете выявила смещение кончика шнура всего на 0.0237 px:
точные ограничения всех рёбер делали плоскую триангулированную сетку почти
жёсткой. Ограничения теперь допускают ограниченную деформацию материала,
а силы учитывают допустимое смещение конкретной детали. При умеренном наклоне
шнуры перемещаются на 5.6–10.9 px; при сильных воздействиях крепления сохраняются
и треугольники не выворачиваются. Корпус получил общий наклон до 8° вокруг
нижней опоры, найденной по геометрии, без индивидуальных настроек Уны.
Новые крайние рендеры повторно прошли VLM QA. На неподвижном Note 10 сигнал
после выравнивания находится возле нуля, прежнее насыщение отсутствует.
После отзыва о слишком большом требуемом наклоне входная чувствительность
увеличена втрое. Зона покоя 0.004 rad подавляет мелкий шум; ограничения
контрольных поз остаются прежними. Регрессия подтверждает заметный отклик
при 5° наклона телефона и отсутствие смещения корпуса при стационарном шуме.
Пользователь подтвердил: «Да, теперь удобно». Чувствительность принята на Note 10.
Прогон предыдущей версии остановлен через 123.29 с перед обновлением;
тайм-аут экрана восстановлен. Его нельзя считать десятиминутной проверкой.

## Прозрачность видео на Android 12

В исходной 0.1.40 обработчик `applyBackgroundKey` возвращался без обработки
на API ниже 33. На Note 10 / Android 12 это оставляло исходный зелёный фон
видеороликов. Добавлен GPU-эффект Media3 1.4.1 для API 26–32; статические
кадры и превью подготавливаются асинхронно с плавной альфой и подавлением
зелёного оттенка. Видео на Android 13+ продолжает использовать существующий путь.
Рабочее цветовое пространство сверено с
[исходным кодом закреплённой версии](https://github.com/androidx/media/blob/1.4.1/libraries/effect/src/main/java/androidx/media3/effect/DefaultVideoFrameProcessor.java).

На Note 10 проверены обычное видео Акима и сон Уны. Сильных зелёных пикселей
на полном снимке Акима было 690243, стало 0 при одинаковом критерии подсчёта.
Сохранены снимки до/после и запись `mascot3-note10-v45-chroma-actions.mp4`.
Выполнена реальная смена Уна → Аким → Уна; физика Уны загрузилась снова.
Короткий прежний прогон после смены героя на Акима остановлен через 44.34 с:
он не считается проверкой физики Уны. Тайм-аут экрана восстановлен.

## Десятиминутный прогон 0.1.44 на Note 10

Завершён полностью: 603.85 с наблюдения, 600.11 с объединённой записи
из четырёх сегментов без повторного кодирования. На всём протяжении контроллер
проверял поступление новых метрик именно от исходного экземпляра физики Уны.
Для статистики использованы 59 окон по 600 кадров, всего 35400 кадров.

| Метрика | Результат |
| --- | --- |
| Средняя частота, взвешенная по времени | 59.83 FPS |
| Частота в отдельных окнах | 59.28–59.98 FPS |
| Среднее время рендера | 3.86 мс |
| Медиана p95 отдельных окон | 7.42 мс |
| Максимум p95 отдельных окон | 9.77 мс |
| Native heap в начале → конце | 42.14 → 41.80 MiB |
| Total PSS в начале → конце | 184.75 → 185.17 MiB |

Java heap колеблется при сборках мусора, native heap немного снизился;
устойчивого роста памяти за этот отрезок не обнаружено. Это ограниченный
десятиминутный тест, а не доказательство отсутствия долгосрочных утечек.
Процентили относятся к окнам в 600 кадров, общий p95 из них не восстанавливался.
Все окна отмечены как откалиброванные; после скрытия экрана зафиксирована
отписка PhoneMotion от всех трёх датчиков. Прежний тайм-аут экрана 300000 мс
восстановлен, процессы записи завершены.

Файлы: `output/physics-pilot/note10-v45-soak/summary.json`, `frames.csv`,
`full-run.mp4`, `memory-*.txt`. Тест проводился с записью экрана на Note 10
вместо S23 по просьбе пользователя; результаты не переносятся автоматически
на другие устройства.
