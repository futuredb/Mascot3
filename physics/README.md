# Физика 2.5D: пилот

Точка отката до реализации: `pre-physics-2026-10-15`, commit
`fb60034300c3e3fad01e85db6b5a00d437b0d7af` на `origin`.
Разработка находится в ветке `codex/mascot-physics`.

## Запуск

```sh
npm ci
npm run physics:prepare                  # только проверка конфигурации, без расходов
npm run physics:prepare -- --submit=yes # один возобновляемый прогон Уны
```

CLI и HTTP используют `PhysicsJobs` и один каталог
`$MASCOT3_DATA_DIR/server-data/physics` (по умолчанию `./server-data/physics`).
Повторный запуск с тем же ключом продолжает имеющееся задание. Разные ключи
для одинакового изображения, нейтрального кадра и контракта также используют
то же задание. Блокировки защищают одновременный запуск CLI и backend.

Для реального прогона в локальном `.env` нужны `REPLICATE_API_TOKEN` и
`OPENROUTER_API_KEY`. Для HTTP дополнительно нужны `MASCOT3_CLIENT_TOKEN` и
`PHYSICS_ENABLED=true`. По умолчанию HTTP-подготовка выключена. Разрешён только
`PHYSICS_PILOT_ID`; это ограничение запуска, в геометрии и движении нет условий
по имени или ID героя. Массового запуска и запуска при генерации нового героя нет.

Модели: BiRefNet — альфа, SAM 3 — отдельные маски, Depth Anything V2 **Small** —
`grey_depth`. Их версии закреплены в `providers.js`. OpenRouter используется для
Gemini 2.5 Flash (структурированный анализ и отдельная проверка качества) и
существующей модели изображений (восстановление скрытых поверхностей).
Ключи этих вызовов используются только на backend. Прежняя генерация героев
на телефоне продолжает использовать свои существующие настройки.

Исходный `base.png` задаёт идентичность пакета. Если есть `videos/neutral.png`,
он задаёт размер, позу и положение в кадре. `--image=...`, `--anchor=...`,
`--contract=...`, `--hero=...`, `--key=...` переопределяют входы CLI.
Для видео без согласованного нейтрального кадра бесшовность не подтверждена.

## HTTP

`X-Mascot-Client-Token` обязателен для всех маршрутов физики.

`POST /v1/physics/jobs` с `Idempotency-Key` и JSON:

```json
{
  "mascot_id": "716cdb43-703b-4d7e-8a79-27f03d92b99c",
  "image_base64": "PNG в base64 без data: префикса",
  "anchor_base64": "необязательный нейтральный PNG",
  "character_contract": {}
}
```

Ответ 202: `id`, `status`, `stage`, `error`, `physics_pack`, `cost`.
`GET /v1/physics/jobs/:id` возвращает эти же поля. Состояния: `queued`,
`running`, `blocked`, `failed`, `ready`. Только `ready` публикует пакет и
позволяет скачивать `/v1/physics/jobs/:id/assets/:file`.

После сбоя известный Replicate prediction опрашивается по сохранённому ID.
Перед каждым платным POST сохраняется маркер. Если ответ потерян до сохранения
ID, результат считается неизвестным: автоматической повторной отправки нет.
Нужно сверить запрос с кабинетом провайдера; удалять маркер для повторной попытки
без такой сверки нельзя. Ответ OpenRouter сохраняется до разбора JSON, включая
ID и стоимость, поэтому некорректный JSON также не покупается повторно.

`providers/*.json` содержит этапы, модели, ID и расходы. `job.json.cost` суммирует
известные долларовые расходы OpenRouter. Replicate возвращает длительность
вычисления, а не точный счёт в долларах: `cost_usd=null`, `complete=false` до
сверки с биллингом. Нулевую стоимость для неизвестного счёта не предполагаем.

## PhysicsPack v1

`manifest.json`: `format=mascot-physics-2.5d`, `version=1`, хеш исходного PNG,
хеш альфы и нейтрального видео-кадра, размер холста, `max_tilt_degrees=12`,
слои, ассеты и результат QA. Текстуры полноразмерные PNG с прозрачностью;
карта глубины числовая серая. Все файлы имеют SHA-256 и размер.

Вершина: `[x/width, y/width, depth, u, v, mobility]`.
`mobility=0` закрепляет вершину, положительное значение задаёт мягкость.
`triangles` — индексы треугольников; `edges` и `bends` —
`[indexA,indexB,restLength]`; `pins` — `[childVertex,parentVertex]`.
Родитель предшествует потомку. Жёсткая дочерняя деталь движется целиком.
`order` задаёт порядок перекрытий. Материалы `hair`, `cord`, `cloth`, `rigid`
имеют разные демпфирование, упругость и предел смещения.

Предложенные VLM крепления привязываются к реальным маскам; далёкие точки,
разорванные части, пересекающиеся маски и некорректная геометрия отклоняются.
Восстановление меняет только пиксели удалённых частей; известная поверхность
за пределами этих масок сохраняется. Это консервативная схема: сложный набор
перекрытий может быть забракован, а не опубликован с дефектами.

QA сохраняет `qa_masks.png`, нейтральный и четыре крайних рендера,
`quality.json`. Нейтральный рендер сравнивается с альфой исходного кадра;
максимальная средняя ошибка premultiplied RGBA — 0.025. Внешний VLM должен
одобрить все шесть критериев. Крайние рендеры проверяют консервативную границу
смещений; они не заменяют просмотр реального движения на устройстве.

## Android

Необязательное поле `physics_pack` манифеста совместимо со старыми героями.
WorkManager скачивает в staging, проверяет весь пакет и исходный PNG, затем
атомарно меняет указатель `active`. Прерванная загрузка сохраняет старый пакет.
При недоступности датчиков, ошибке загрузки или QA остаётся прежний видеорежим
со статусом. У пилота есть явная кнопка подготовки; скрытых платных запусков нет.

Прозрачный TextureView рендерится отдельным потоком OpenGL ES 3. Движение
получает системные rotation vector, gravity и linear acceleration, учитывает поворот
экрана, калибрует нейтраль и ограничивает воздействия. Решатель выполняет
Verlet-предсказание и ограничения креплений, растяжения, изгиба и ориентации
треугольников с шагом 1/120 с, максимум шесть шагов на кадр. Корпус поворачивается
через пружину, мелкие части имеют инерцию. Датчики и симуляция останавливаются
в фоне и во время видимого действия; при возобновлении время и скорости
сбрасываются. Ресурсы EGL освобождаются владельцем поверхности. При потере
контекста текстуры, буферы и программа создаются заново из локального пакета;
восстановление ограничено двумя попытками за 600 кадров. Ошибка восстановления
переключает героя в прежний режим.

Перед действием физика возвращается в нейтраль, затем переключается на первый
декодированный кадр без растворения. Последний кадр удерживается до готовности
нейтральной физики. Сон использует существующий видеоплеер и его цикл.

Диагностика пишет ограниченные CSV в
`Android/data/app.mascot3/files/physics-metrics/`: FPS по интервалам кадров,
среднее и p95 времени рендера, Java/native heap. Эти значения требуют реального
прогона; JVM-тесты не доказывают производительность GPU.

## Проверка и выпуск

```sh
npm test
npm run check
JAVA_HOME=/path/to/jdk17 ./android/gradlew -p android \
  :app:testDebugUnitTest :app:lintDebug :app:assembleDebug \
  -PMASCOT3_TEST_JAVA_HOME=/path/to/jdk21-or-newer
```

Перед production-сборкой обязательны: реальная подготовка Уны, визуальное
одобрение ±12°, приветствие/танец/сон/возврат, пауза/смена героя/поверхности,
10 минут на S23, CSV и запись экрана, сверка стоимости. После этого —
`update-compatible` APK с проверкой сертификата и `adb install -r` без очистки
данных и без прерывания активной генерации. Пока реальный пакет не проверен,
сборка debug служит только проверкой компиляции и упаковки.
