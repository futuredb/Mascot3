# Маскот 3

Маскот 3 — Android-приложение для создания и оживления персонажей. В нём есть библиотека героев, чат, виджет и режим «Герой рядом».

**Опубликованная версия с новым интерфейсом и Helios находится в ветке [`stable/newUI-2026-11-05`](https://github.com/futuredb/Mascot3/tree/stable/newUI-2026-11-05).** В ней Android `0.1.107-helios-identity` и исходный промпт Helios до эксперимента с сокращением. Инструкции по запуску и карта проекта находятся в [README этой ветки](https://github.com/futuredb/Mascot3/blob/stable/newUI-2026-11-05/README.md).

Ветка `main` содержит раннюю версию Android `0.1.40`. Её настройки сборки, профиль генерации и историю релизов можно найти в [архивном README](https://github.com/futuredb/Mascot3/blob/fb60034300c3e3fad01e85db6b5a00d437b0d7af/README.md).
