# Маскот 3

Android-приложение для создания и оживления маскотов. Можно выбрать встроенного героя или создать своего, переписываться с ним и выводить его на рабочий стол через виджет или поверх приложений через «Герой рядом».

Этот README описывает опубликованную ветку [`stable/newUI-2026-11-05`](https://github.com/futuredb/Mascot3/tree/stable/newUI-2026-11-05), Android `0.1.107-helios-identity` (код версии `108`, пакет `app.mascot3`). Это снимок до эксперимента с коротким промптом Helios. Ветка `main` содержит более раннюю версию `0.1.40`.

## Что есть в этой версии

- **Создание героя.** Один фронтальный референс. После принятия героя запускается приветствие, остальные анимации можно заказывать отдельными партиями из библиотеки.
- **Живые реакции.** В Android-чате Helios получает референс персонажа и команду на движение. Встроенный WebView принимает видеодорожку по WebRTC и рисует кадры на `canvas`.
- **Виджет и «Герой рядом».** Сохранённые анимации, реакция на наклон телефона и подготовленные данные глубины для освещения. [Описание оверлея](docs/overlay-mvp.md).
- **Хранение.** Android хранит локальную библиотеку. Node.js-сервер хранит серверные данные героев, задания и учёт расходов в постоянном каталоге данных.

## Локальный запуск

Для основного сервера нужна Node.js 20.19.5 или новее. Параметры окружения перечислены в [`.env.example`](.env.example).

```bash
npm ci
npm start
```

Сервер слушает порт `8788`. Для эмулятора или устройства с ADB можно открыть доступ к локальному серверу через `adb reverse tcp:8788 tcp:8788`.

Для Android нужны JDK 17 и Android SDK 36. Из корня репозитория:

```bash
./android/gradlew -p android :app:assembleDebug
```

Подписанные сборки используют отдельную конфигурацию. Для обновления установленной версии нужен APK с тем же сертификатом подписи. [Сборка Android-релиза](android/PRODUCTION_BUILD.md) · [Сборка update-compatible](scripts/build-android-update-compatible.mjs).

## Превью Codex

Для веб-превью чата нужна Node.js 22 или новее.

```bash
cd live-chat
npm ci
npm start
```

Открой [чат](http://127.0.0.1:8810/) или [локальные проверки без платных запросов](http://127.0.0.1:8810/qa) в превью Codex. Поток Helios в Android подключается отдельно через Reactor.
